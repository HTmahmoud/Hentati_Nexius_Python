💱 Convertisseur Euro/Dollar

Une application moderne de conversion de devises entre euros et dollars en temps réel, développée avec React et Ant Design.

✨ Démo
L'application est disponible en ligne à l'adresse: https://htmahmoud.github.io/Hentati_Nexius_Python/

🚀 Installation

	1-Clonez le dépôt
	git clone https://github.com/HTmahmoud/Hentati_Nexius_Python.git

	2-Installez les dépendances:
	npm install

	3-Lancez l'application en mode développement
	npm start

🛠️ Technologies utilisées

	-React 18 - Une bibliothèque JavaScript pour créer des interfaces utilisateur
	-Ant Design 5 - Un système de design avec un ensemble de composants de haute qualité
	-JavaScript ES6+ - Standards modernes de JavaScript
	-CSS3 - Pour le styling avancé
	-GitHub Pages - Pour l'hébergement de l'application

🐳 Démarrer l'application avec Docker

	1-Construire et démarrer le conteneur de développement :
	docker-compose -f docker-compose.dev.yml up

	2-Pour exécuter en arrière-plan (mode détaché) :
	docker-compose -f docker-compose.dev.yml up -d

	3-Pour afficher les logs en mode détaché :
	docker-compose -f docker-compose.dev.yml logs -f
